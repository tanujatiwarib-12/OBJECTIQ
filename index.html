About this prototype

What is implemented
Implemented: webcam access, image upload, live object detection, bounding boxes, confidence scores, threshold control, session activity, and browser text-to-speech.
Model: COCO-SSD via TensorFlow.js with the MobileNet V1 backbone. It supports the 80 standard COCO object categories listed below.
Limit: this is not a general-purpose AI assistant. It only recognises classes supported by the model; performance depends on lighting, camera quality, and network access when loading the model.
OBJECTIQ · Student prototype · Use responsibly and respect people’s privacy when using a camera.
